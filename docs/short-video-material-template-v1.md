## 模板结构

### 1. 脚本结构模板（15s/30s/60s）

#### 15秒短视频脚本骨架
```
【开场钩子】0-3s
- 痛点/问题抛出（字幕+画面）
- 口播：一句直击痛点

【方案展示】3-10s  
- AI生成效果/案例展示（3-5个镜头快切）
- 口播：核心价值点

【CTA落版】10-15s
- 引导行动（扫码/留资/咨询）
- 口播：一句CTA
```

#### 30秒短视频脚本骨架
```
【开场钩子】0-5s
- 痛点/场景带入
- 口播：问题描述

【方案拆解】5-18s
- 步骤1/2/3图示
- 口播：解决方案

【案例展示】18-25s
- 前后对比/效果展示
- 口播：案例背书

【CTA落版】25-30s
- 引导行动
- 口播：一句CTA+利益点
```

#### 60秒短视频脚本骨架
```
【开场钩子】0-8s
- 痛点放大+数据/场景

【问题分析】8-20s
- 原因拆解（2-3点）
- 口播：深度分析

【解决方案】20-40s
- 方案详述（步骤化）
- 口播：价值主张

【案例实证】40-52s
- 详细案例展示
- 口播：实证背书

【总结+CTA】52-60s
- 核心要点回顾
- CTA引导
```

### 2. 封面标题模板

#### 痛点型标题
```
模板：{痛点描述}？{解决方案}
示例：
- 旧房越住越压抑？3招立刻提升幸福感
- 奶油风总翻车？记住这4个避坑指南
- 装修预算不够？为什么你更该做"轻焕新"
```

#### 对比型标题
```
模板：{A} vs {B}：{差异点}
示例：
- 复杂堆料 vs 克制统一：奶油风高级感分水岭
- 全屋重装 vs 局部焕新：哪个更适合你
- 先出图再装修 vs 开工再返工：成本差10倍
```

#### 清单型标题
```
模板：{数字}+{主题}清单
示例：
- 奶油风不翻车检查清单（4项必过）
- 旧房焕新高回报清单（先做这3步）
- 智能家居入门清单：预算有限也能做
```

### 3. 前后对比组件调用方式

在落地页中使用滑杆对比组件：

```jsx
// 对比滑杆组件使用示例
<div className="relative aspect-video rounded-xl overflow-hidden bg-gray-100">
  <img src={beforeImage} alt="改造前" className="absolute inset-0 w-full h-full object-cover" />
  <div className="absolute inset-0" style={{ clipPath: `inset(0 ${100 - comparePosition}% 0 0)` }}>
    <img src={afterImage} alt="改造后" className="w-full h-full object-cover" />
  </div>
  {/* 滑杆控制 */}
  <input
    type="range"
    min={0}
    max={100}
    value={comparePosition}
    onChange={e => setComparePosition(Number(e.target.value))}
    className="w-full mt-4"
  />
</div>
```

## 验收标准

1. 脚本模板：3套（15s/30s/60s）骨架完整，每套含镜头/时长/口播
2. 标题模板：3类（痛点/对比/清单）各3+条可套用
3. 组件调用：有可直接复制使用的React组件代码
4. 命名规范：有明确的中英文命名规则
5. 版本表：有可直接导入的表格模板（含必填字段）
